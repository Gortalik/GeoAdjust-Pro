# Тестовая сборка GeoAdjust Pro

## Варианты запуска без сборки exe

### 1. Полный тестовый запуск (рекомендуется)

Для полной проверки всех компонентов:

```bash
python test_launch.py
```

Этот скрипт:
- Проверяет импорты всех основных модулей
- Тестирует создание QApplication (GUI фреймворк)
- Запускает полное приложение

### 2. Быстрый запуск GUI с тестовым проектом

Для быстрого тестирования интерфейса с автоматически созданным проектом:

```bash
python test_gui_launch.py
```

Этот скрипт:
- Создает временный тестовый проект
- Открывает главное окно приложения
- Позволяет протестировать интерфейс без ручного создания проекта

## Преимущества тестовой сборки

- Мгновенный запуск без ожидания компиляции
- Полная отладка - изменения применяются сразу
- Можно использовать Python отладчик и профилировщик
- Все зависимости уже проверены и установлены

## Проверка зависимостей

Зависимости проверяются автоматически, но можно проверить вручную:

```bash
cd GeoAdjustPro
python check_deps.py
```

Если отсутствуют зависимости:

```bash
pip install -r GeoAdjustPro/requirements.txt
```

## Запуск модульных тестов

Для проверки отдельных компонентов:

```bash
python test_app_launch.py
```

## Сборка exe файла

Когда тестирование завершено, для создания дистрибутива:

```bash
cd GeoAdjustPro
pyinstaller P-of-Geo-Meas.spec --clean --noconfirm
```

## Отладка проблем

Если GUI не запускается:
1. Проверьте наличие дисплея (на Windows должен работать)
2. Убедитесь, что PyQt5 установлен корректно
3. Проверьте логи в файле `geoadjust.log`
4. На Linux установите переменную DISPLAY или используйте X11 forwarding

Этот скрипт:
- Проверяет наличие зависимостей
- Добавляет пути к исходному коду
- Запускает приложение в режиме разработки

## Преимущества тестовой сборки

- Быстрый запуск без ожидания сборки
- Легче отлаживать ошибки
- Можно использовать отладчик Python
- Изменения в коде применяются сразу
