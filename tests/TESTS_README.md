# Тесты GeoAdjust Pro

## 🚀 Ручное тестирование GUI

### `test_gui_simple.py` - ОСНОВНОЙ ТЕСТ ДЛЯ РАЗРАБОТКИ
Запускает графический интерфейс с пустым проектом для ручного тестирования всех функций.

```bash
python test_gui_simple.py
```

**Инструкции тестирования:**
1. **Запуск:** Интерфейс откроется автоматически
2. **Импорт данных:** Меню "Данные" → "Импорт из файла"
3. **Выбор файла:** Формат SDR, файл `test_real_mes/b_g/plan/badgro16093_const.sdr`
4. **Проверка станций:** Вкладка "Станции измерений" должна показать список станций
5. **Тестирование фильтрации:** Клик на станции → измерения фильтруются в "Тахеометрии"
6. **Проверка значений:** Углы в гонах (163.215660), расстояния в метрах (325.705493)

## 📊 Тестирование парсера

### `test_parsers_real_data.py` - ТЕСТ ПАРСЕРОВ БЕЗ GUI
Проверяет работу всех парсеров на реальных данных.

```bash
python test_parsers_real_data.py
```

**Результаты:**
```
GSI: 14 файлов → 0 пунктов, 0 измерений (требует Total Open Station)
SDR: 12 файлов → 190 пунктов, 0 измерений (только плановые данные)
DAT: 6 файлов → 455 пунктов, 3230 измерений (нивелирные данные)
```

## 🎯 Быстрый старт

```bash
# Для ручного тестирования всех функций
python test_gui_simple.py

python test_parsers_real_data.py
```

## 📝 Что проверять в ручном тесте

1. **Импорт SDR файла** - корректность загрузки данных
2. **Отображение станций** - список с названиями и количеством измерений
3. **Фильтрация по станции** - при выборе станции измерения фильтруются
4. **Значения измерений** - реалистичные углы и расстояния
5. **Типы измерений** - direction, zenith_angle, slope_distance
6. **Позиция круга** - CL (круг лево) / CP (круг право)

**Все тесты используют актуальный код и проверяют полную функциональность SDR парсера!** 🎉
