# GeoAdjust Pro - Рабочий прототип

Полностью функциональная геодезическая программа с графическим интерфейсом.

## 🚀 Запуск

```bash
python GeoAdjustPro_Prototype.py
```

## ✨ Возможности

### 📊 Управление данными
- Создание и управление геодезическими проектами
- Импорт данных из SDR файлов
- Таблицы пунктов и измерений с визуальными индикаторами типов

### 🗺️ Графическое отображение
- План-схема геодезической сети с адаптивной сеткой
- Визуальные индикаторы типов пунктов (опорные, свободные, приближенные)
- Отображение измерений с цветовым кодированием типов

### ⚙️ Обработка данных
- Предобработка (9 этапов: топология, ходы, приемы, редукции и т.д.)
- Уравнивание сети методом классических МНК
- Контроль допусков по СП 11-104-97

### 📋 Ведомости и отчеты
- Ведомость координат с оценками точности
- Ведомость топологии сети
- Ведомость оценки точности с эллипсами ошибок

## 🎨 Визуальные индикаторы

### Типы пунктов:
- **FIXED** (опорный): ● Синий круг
- **FREE** (свободный): ○ Красный круг
- **APPROXIMATE** (приближенный): △ Оранжевый треугольник

### Типы измерений:
- **direction** (направление): → Зеленый
- **slope_distance** (расстояние): ↗ Оранжевый
- **zenith_angle** (зенитный угол): ∠ Фиолетовый
- **height_diff** (превышение): ↕ Пурпурный

### Типы ходов:
- **taheometric** (тахеометрия): ⊕ Зеленый
- **leveling** (нивелирование): ━ Фиолетовый
- **gnss** (GNSS): ◎ Голубой

## 🖥️ Интерфейс

### Меню
- **Файл**: Создание, открытие, сохранение проектов
- **Правка**: Операции с данными
- **Вид**: Переключение между таблицами и планом
- **Обработка**: Предобработка и уравнивание
- **Отчёты**: Создание ведомостей

### Рабочая область
- **План**: Графическое отображение сети
- **Таблицы**: Пункты и измерения по типам
- **Статусная строка**: Индикаторы операций
