# GeoAdjust Pro - ПОЛНОЦЕННАЯ СИСТЕМА
Профессиональная система уравнивания геодезических сетей

## 🚀 Быстрый запуск

```bash
python run_geoadjust_pro.py
```

## 📁 Структура проекта

### Основное приложение
- `GeoAdjustPro/` - Полноценное приложение
  - `src/geoadjust/` - Исходный код
  - `dist/GeoAdjustPro/GeoAdjustPro.exe` - Скомпилированное приложение
  - `resources/` - Иконки, стили, данные геоида

### Прототипы и тесты
- `run_geoadjust_pro.py` - Запуск основного приложения
- `gui_prototype.py` - Упрощенная GUI версия
- `working_prototype.py` - Консольная версия
- `tests/` - Полный набор тестов
- `test_real_mes/` - Реальные геодезические данные

## Возможности прототипа

### GUI интерфейс
- **Меню Файл**: Новый проект, открытие файлов
- **Меню Данные**: Импорт из GSI, SDR, DAT файлов
- **Меню Вид**: Переключение между планом, таблицами пунктов и измерений
- **Меню Обработка**: Предобработка данных (9 этапов), уравнивание МНК
- **Меню Отчёты**: Ведомости координат, топологии, точности (HTML)

### Графическое отображение
- Интерактивный план сети с цветовой индикацией типов пунктов
- Отображение измерений разных типов линиями разных цветов
- Автомасштабирование и навигация по плану

### Таблицы данных
- Таблица пунктов с координатами и типами
- Табулированные измерения по типам (направления, расстояния, углы, превышения)

### Обработка данных
- Парсинг форматов: Leica GSI, Sokkia SDR, DAT
- Простое уравнивание методом наименьших квадратов
- Генерация HTML отчетов

## Реализованные функции (ПОЛНАЯ ВЕРСИЯ)

### 🎯 Основные возможности
- **15+ форматов приборов**: Leica GSI/DAT, Sokkia SDR, Trimble M5/JobXML, Topcon GTS, Nikon, Geodimeter, УОМЗ
- **9 этапов предобработки** с контролем 27 нормативных допусков
- **Параметрическое уравнивание** методом наименьших квадратов (Ю.И. Маркузе)
- **Робастные методы**: Хьюбера, Тьюки, L1-минимизация
- **Анализ надёжности**: Теория Баарда, внутреняя/внешняя надёжность
- **5 методов поиска грубых ошибок**: стандартизованные остатки, трассировка ходов

### 🗺️ Системы координат
- **Полная база СК РФ**: СК-42, СК-95, ГСК-2011, МСК 128 субъектов
- **Преобразования координат**: 7 параметров Гельмерта
- **Модели геоида**: EGM2008, Рус-геоид-2011
- **Проекция Гаусса-Крюгера**

### 📊 GUI интерфейс
- **Два типа интерфейса**: Классический (меню+тулбары) и Ленточный (Ribbon)
- **Интерактивный план сети** с визуальными индикаторами
- **Таблицы данных** с цветовой индикацией типов измерений
- **Обработка в реальном времени** с прогресс-барами
- **Визуальные индикаторы** для всех типов данных

### 📋 Отчётность
- **ГОСТ 7.32-2017**: Автоматическая нумерация формул
- **Ведомости**: координаты, поправки, топология, точность
- **Экспорт**: DXF, DOCX, HTML, PDF
- **Сертификат соответствия** нормативным требованиям

### 🔧 Архитектура
- **Модульная структура**: GUI, Core, IO, CRS
- **Обработка в потоках**: Не блокирует интерфейс
- **История изменений**: Откат операций
- **Конфигурация**: Трехуровневая иерархия настроек
