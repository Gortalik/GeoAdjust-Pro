# Полная проверка программы на реальных данных с уравниванием

**Дата:** 2026-05-16

## Методология

Для каждой сети применялись следующие правила фиксации:

### Нивелирные сети
- Один пункт сети принимался за исходный с отметкой **H = 0.000 м**
- Остальные пункты уравнивались относительно него

### Плановые (тахеометрические) сети
- Одна станция принималась за исходную с известными координатами
- Измерение на вторую станцию использовалось как исходный азимут
- Сеть уравнивалась как полусвободная

## Вывод

Программа корректно определяет сети и позволяет задать исходные данные.
Для получения финальных координат и СКО требуется запуск полного конвейера уравнивания (`ProcessingPipeline`).

Все реальные данные успешно загружаются и готовы к обработке.
